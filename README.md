# FHD_TestMod

Мод-инструментарий для Space Rangers HD: A War Apart.

## Структура
- `source/` — актуальные исходные файлы проекта.
- `releases/` — готовые архивы мода и контрольные суммы.
- `docs/` — документация и результаты проверок.

## Важная настройка совместимости

В `ModuleInfo.txt` намеренно сохраняется строка:

```ini
Conflict=DevKit
```

Это рабочая настройка совместимости. Её нельзя удалять или переименовывать в рамках перехода на FHD_TestMod.

## Правила публикации
1. Не менять игровую логику при переименовании.
2. Сохранять `Conflict=DevKit`.
3. Не переносить старые сборки без проверки.
4. Фиксировать состав архива и SHA-256 каждого релиза.
5. Публиковать DLL- и NO_DLL-варианты отдельно.
6. Не включать посторонние игровые файлы, инструменты и секреты.
