# FHD_TestMod

Мод-инструментарий для Space Rangers HD: A War Apart.

## Структура
- `source/` — восстановленная редактируемая база исходных данных и инструменты.
- `releases/` — контрольные суммы и сведения о готовых сборках.
- `docs/` — документация и результаты проверки.

## Правила публикации
1. Переименование не должно менять игровую логику.
2. Сборки DLL и NO_DLL публикуются раздельно.
3. Для каждого релиза фиксируются состав архива и SHA-256.
4. Перед публикацией проверяются пути, содержимое, манифест и совместимость.
