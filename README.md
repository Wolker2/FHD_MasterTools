# FHD_TestMod

Мод-инструментарий для Space Rangers HD: A War Apart.

## Структура
- `source/` — актуальные исходные файлы проекта.
- `releases/` — готовые архивы мода и контрольные суммы.
- `docs/` — документация и результаты проверки

## Правила публикации
1. Не менять игровую логику при переименовании.
2. Не переносить старые сборки без проверки.
3. Фиксировать состав архива и SHA-256 каждого релиза.
4. Публиковать DLL- и NO_DLL-варианты отдельно.
5. Не включать посторонние игровые файлы, инструменты и секреты.
